# FAQ Chatbot

A simple NLP-based FAQ chatbot built with Python, Flask, NLTK,
TF-IDF, and cosine similarity.

## Features

- FAQ-based question answering
- NLP preprocessing
- Lowercase normalization
- Tokenization
- Stop-word removal
- Stemming
- TF-IDF vectorization
- Cosine similarity matching
- Similarity threshold
- Flask API
- Responsive chatbot UI
- Automated tests
- Vercel deployment support

## Technology Stack

- Python 3.14
- Flask
- NLTK
- Scikit-learn
- HTML
- CSS
- JavaScript
- uv
- Vercel
